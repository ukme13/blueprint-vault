# 2026-09-10 — Named preview devices, shared specimen copy, hybrid role size

Work on `feat/hybrid-tokenized-input`, on top of the hybrid field that already
binds scale ratio and spacing (`5e2ff1d`). The studio's preview stopped being a
hide/show of three widths and became a small set of named frames, each with its
own size and ratio. Role size in the Groups tab uses the same hybrid field.

## Preview devices

Phone, tablet and desktop always stay. A project may add up to two extra
desktop sizes (1440 then 1920 by default) and never invents a fourth kind of
device. Required rows show a lock; extras show a remove control. Add desktop
uses the same contained primary button as Add font.

Each frame stores `widthPx` and `ratio`. `TypeSystem.ratio` remains the
canonical **desktop** ratio for export. Editing the desktop row writes both.
Switching a nav icon regenerates the type steps from that frame's ratio, so
the inspector and the preview agree on the ramp you are looking at.

A legacy save stored which of the three frames were visible. Those lists no
longer hide a required frame — missing ones are filled back from the defaults,
and the old `mobile` id becomes `phone`.

Which frames exist persists with the project. Which frame is active is view
state and resets on reload.

## Templates and copy

The studio offers Specimen and Article. Marketing was removed. So was the Thai
language toggle. Preview copy is the editor specimen, so a person types once
and judges the scale in the same string, including scripts the canned
English/Thai pair never covered.

Documentation still renders the canned bilingual articles. Templates live in
the package so both apps draw the same layout; the host supplies class names
and, for the docs page, a heading level that does not steal the page outline.

Editor and Preview sit on the typography toolbar (`aria-label="Typography
views"`), not on the workspace top bar. Workspace nav is still Colour /
Typography / Scale / Preview. Playwright has to ask for the Preview **button**
with `exact: true`, or it matches the workspace Preview **link**.

## Groups tab size

Role size is a hybrid tokenized field. A bound chip reads like `16 (+0)`;
typing a px size unlinks (`stepOffset: null`); picking a step relinks.
`hybridValueFromStepOffset` is the domain helper so the editor does not
rebuild that shape locally. The helper is exported by name, not via `export *`
of every `format*` — the export-guard test treats every `format*` as a
document formatter.

## Layout that was eating input

Preview background paints on each card (`--preview-surface`), not on the
stage, so text and background apply independently. The stage is a grid with
no `overflow: hidden`, because that ate wheel events. Workspace and editor
clip instead, so absolutely positioned hidden file inputs cannot stretch
`documentElement.scrollHeight`. `.inspector` must not be `position: relative`:
it became the popover containing block and clipped the hybrid menu on a short
viewport.

Add-font / add-group / add-desktop share `.addEntryButton`. Stretching them
on a 320px window cannot rely on the inspector container query alone: the
panel can still lay out at `--inspector-width` while the visible box is
clipped. A viewport rule at 360px matches what a person actually sees.

## Lessons

**A legacy hide/show list is not a device model.** Restoring a missing phone
frame is migration. Offering a checkbox to hide it was a preference that made
the nav lie about what you were designing for.

**The active ratio is a way of looking, until it isn't.** Extra desktops can
diverge. Export still has one ramp. Desktop is that ramp. Phone and tablet
are views of it, stored on the frame so they survive a reload.

**`name: "Desktop"` is a substring.** Playwright's accessible-name match
includes "Desktop 2". `exact: true` is the difference between clicking the
required frame and clicking the extra one you just added.

**Container queries see layout size, not the clipped box.** `overflow: hidden`
on the workspace made the inspector _look_ 294px wide while it was still 560.
The add buttons stayed at 9rem in a gap that looked empty. Ask the viewport
as well, or actually shrink the panel.

**Do not `export *` a `format*` helper** unless it serialises a document. The
guard enumerates the barrel. `hybridValueFromStepOffset` is named on purpose.

**A MetaMask overlay on localhost is the extension**, not the app. There is
no wallet code in this repo.
