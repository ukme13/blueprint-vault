# 2026-08-28 — Typography fonts, and a dependency upgrade

## What was done

**Dependencies.** A staged upgrade, one stage per branch: the pnpm and Node
floor, then the framework packages, then TypeScript 6.0.3. ESLint 10 and
TypeScript 7 were both scouted and both deferred — ESLint 10 is blocked by
`eslint-plugin-react`, TypeScript 7 by `typescript-eslint`. The reasoning is in
[dependency-upgrade.md](../roadmap/dependency-upgrade.md).

`CLAUDE.md` gained a package rule: check the real version with `npm view`, read
the current online docs before writing code against a library, stable releases
only, and never bump a major silently.

**Typography.** The role table's labels were resized, the H/body lock removed,
and group renaming fixed. Then fonts: a Google Fonts picker that loads at
runtime, a bilingual fallback filtered by writing system, a display/main font
pair, per-entry add/rename/remove, a preview-font selector for the step list,
and a preview weight limited to what the family ships.

Sizes now round to even pixels with a floor of 11, and the exact value is kept
alongside the rounded one.

## What was learned

**Astryx's Typeahead does not put the selection in the input.** It renders the
chosen value as a token button and collapses the input to zero width — this is
deliberate, and `BaseTypeahead` documents it as a WCAG 2.4.3 concern. Two
consequences: `toHaveValue` never sees the selection, and `fill()` on a picker
that already holds a value times out. Tests clear the token first.

**A manual `useMemo` can stop the React Compiler compiling a component at all.**
The warning reads "Compilation Skipped: Existing memoization could not be
preserved". Moving the pure computation to a module-level function fixed it —
the compiler then memoizes it automatically, which is better than the hand-rolled
version it replaced.

**Playwright's `line` reporter hides failures.** It overwrites its own output
with carriage returns, so a saved log can end in "29 passed" while the run
actually failed. `test-results/.last-run.json` is the honest record, and
`--reporter=list` keeps every line.

**Verify that a string replacement matched.** `str.replace` returns the string
unchanged when the pattern is absent, so a script can report success having
done nothing. One edit was reported as applied when it was not, and the mistake
survived two test runs. Every replacement now asserts its match count.

**Prettier corrupts CSS token syntax in markdown.** It reads the `*` in a
wildcard token reference as emphasis and rewrites it. The agent-facing markdown
files are in `.prettierignore` for that reason.

**A parser bug can be silent and lossy.** The font catalogue generator sliced
weight strings with `k[:3]`, which read `"1000"` as `100` — 21 families quietly
lost their heaviest weight. The fix is a regex anchored to the digits. The
first correction attempt was also wrong: filtering out weights under 100 would
have dropped legitimate ones, since CSS font-weight starts at 1 and ten variable
families use that.

**Test seeding races the app.** Writing `localStorage` after `page.goto` raced a
mount effect that clears it; ten tests were flaky and the suite took 5.9
minutes. Moving the seed into `addInitScript` took it to zero flaky and about 55
seconds.
