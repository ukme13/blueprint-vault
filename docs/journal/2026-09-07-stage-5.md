# Semantic table stage 5

Stage 5 is on `feat/semantic-table-alpha`, based on Stage 4b. It is local only
and has not been pushed.

## What changed

- Semantic references now expose a right-docked alpha percentage in the table.
  Transparent rows show the value; opaque rows reveal `100%` on hover or focus
  without moving the reference chip.
- `TransparencySwatch` adds a token-based checkerboard underlay to transparent
  reference chips. `SemanticAlphaField` uses Astryx `TextInput`; the existing
  Astryx `Popover` remains the track and weight picker. Astryx provides no
  native checkerboard swatch.
- Alpha supports Tab, Enter, Up/Down and Shift+Up/Down, Escape cancellation and
  coalesced undo keys. The export preview keeps its primitive alias and emits
  `color-mix(...)` for transparent references.
- Seeds now represent real overlays, disabled foregrounds and hover tints with
  alpha rather than only opaque values.
